# A-Game Journal

The journal athletes fill in after each practice or game, for A-Game Coaching
(Steven Griffith). Served by GitHub Pages from `main`.

- Page: `index.html` (one self-contained file, no build step)
- Personal links: `?a=First%20Last` (name filled in and locked), optional `&team=...`
- Kajabi lesson: `?embed=1&src=Kajabi`
- Saves go to the A-Game Journal Google Apps Script web app (`SHEET_ENDPOINT` in the page).

The source of truth is `A-Game-Journal/agame-journal.html` in the private
A-Game repo; keep this copy identical to it.
